# HDLSS5 1.2

See the current [README](../README.md) for the complete feature overview and screenshots.

The published archive currently uses HDLSS.exe. Build scripts now target HDLSS5.exe and preserve the existing data location and instance mutex. The renamed binary has not replaced the release asset because Windows Defender detected Trojan:Win32/Bearfoos.A!ml during its launch check. This detection has not been classified as a false positive. No antivirus exclusion was added.

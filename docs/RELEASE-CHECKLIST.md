# Release checklist

For every release or visible interface change:
- Build and verify the executable and six-language guide/changelog.
- Regenerate screenshots from that exact build for every main category.
- Check the screenshots visually, including narrow and wide window layouts.
- Refresh README and release images; remove links to obsolete interface screenshots.
- Label demonstration profiles accurately and avoid personal data in screenshots.
- Update branding assets whenever the app name or logo changes.
- Verify image links on GitHub after publishing, together with release assets and hashes.

Persistent user requirement: GitHub images describing the app must always be updated.
